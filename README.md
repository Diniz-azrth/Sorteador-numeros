# 🔢 Sorteador de números

Este projeto é um sistema de sorteio de números não repetidos desenvolvido em JavaScript, HTML e CSS, onde o usuário define a quantidade de números desejada e o intervalo numérico personalizado.

## 🚀 Funcionalidades

* **Sorteio Personalizado**: Permite sortear uma quantidade específica de números dentro de um intervalo definido (de / até).
* **Validação de Duplicatas**: Garante que os números gerados no sorteio não se repitam.
* **Reiniciar Sorteio**: Limpa os campos de entrada e reseta os resultados para um novo sorteio.

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica da interface do sorteador.
* **CSS3**: Estilização visual customizada com gradientes e layout responsivo.
* **JavaScript**: Manipulação do DOM e lógica de geração de números aleatórios.

## 📂 Estrutura do Projeto

* **index.html**: Página principal com a estrutura da interface.
* **estilo.css**: Folha de estilos responsável pelo design visual.
* **app.js**: Script contendo a lógica de sorteio, validação e reinicialização.
* **imagem/**: Pasta contendo os recursos visuais e imagens da aplicação.

## 📦 Como Rodar o Projeto

1. Clone o repositório em sua máquina.
2. Certifique-se de manter toda a estrutura de pastas e arquivos intacta.
3. Abra o arquivo `index.html` diretamente em qualquer navegador web para testar a aplicação.
